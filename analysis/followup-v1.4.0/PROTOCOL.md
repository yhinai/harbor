# Unattended independent proxy study · v1.4.0

This is a new follow-up study. It does not replace the frozen Day 1 submission, reinterpret the original 24 interrupted attempts as reasoning failures, or supply the evaluator's missing overnight results. No report.md is created.

**Reported authorization:** the user explicitly authorized paid parallel trials, removed the previous dollar ceilings, and described Fireworks credits as unlimited on 2026-10-08. Actual account credit availability is **unknown**. The study is finite: three tool-use smokes, then eight independent trials per compatible proxy family per task, up to 120 primary panel trials. Smokes are excluded from pass rates. Only Kimi K3, GLM-5.3 and DeepSeek V4.1 Flash are selected. Fable and every GPT-5.6 model are prohibited by the client allowlist.

**Verified infrastructure:** the execution machine identifies itself as mini, with Apple M6, 12 CPU cores and 16 GiB RAM; reached using the existing SSH alias `matrix`. Colima has 10 vCPUs and 12 GiB configured, leaving 4 GiB host RAM. The offline Harbor integration and all five canonical oracles passed again. The 457 original archive artifacts were rechecked and existing loose frozen artifacts matched. See preflight/ for actual evidence.

**Dispatch:** at most ten trials run concurrently. Each has a fresh container and fresh conversation; no previous solution or trajectory is supplied. Task main containers retain their frozen 1 GiB memory and two virtual CPU limits, share the VM CPU scheduler, and have strict Docker network_mode=none through a host overlay. The unused Harbor sidecar is restricted to 64 MiB and 0.25 CPU. A trusted host check verifies network mode before inference. New dispatch waits when VM MemAvailable is below 1536 MiB or host disk free space below 10 GiB. Shared hardware and provider conditions can correlate failures; independent initialization does not establish statistical independence of all outcomes.

**Raised limits:** 1,048,576 requested output tokens, reasoning_effort=max, temperature=1, 1,000 turns, 24 hours agent time and 12 minutes verifier time per trial. The client has no absolute deadline for an active model stream; inactivity allowance is one hour. Connect/write/pool allowance is 120 seconds. Individual terminal calls default to 120 seconds and permit 600 seconds. Command output retains existing bounded capture and background-child cleanup. Provider context limits and service policies still apply. The max-effort parameters and real terminal calls must pass the actual smokes before the family enters the panel.

**Failure accounting:** reward 0 or 1 counts only with real terminal work, no recorded censor or exception, and no grader infrastructure error. Transport, protocol, time, output and turn limits are recorded separately. No graded failure is retried. Operational interruptions can receive up to two fresh replacement attempts, never a continuation of an ambiguous paid request. HTTP 429 rejected requests alone have up to 30 bounded backoff attempts; other ambiguous requests are not replayed. Credentials or billing rejection stop new dispatch. Exhausted replacements remain missing evidence, not zero rewards.

**Persistence:** a system launchd service runs as matrix with caffeinate while active, without an SSH session. A file lock prevents duplicate supervisors. A crash preserves partial artifacts, marks unfinished attempts interrupted, removes only that study's stale containers, and can resume fresh replacements. Five supervisor starts are allowed before a protective stop. Reboots can still interrupt active requests. A VM daemon outage pauses/fails dispatch rather than inventing outcomes. Completion stops paid dispatch and releases the sleep assertion.

**Evidence and synchronization:** full model messages, reasoning, tool calls, outputs, stream events, reported usage and raw Harbor rewards remain in ignored raw job directories. Completed trajectories and submission artifacts are compressed and hashed into versioned evidence. Status and ledger snapshots are committed after smokes, every twenty panel attempts, and completion. Pushes are fast-forward only and verified against origin/main. An unrelated staged change or failed push preserves local evidence and records the blocker. Mutable state and all credentials remain ignored.

**Cost:** no dollar cap is imposed under the latest authorization; finite trial and recovery counts constrain the work. The ledger records provider tokens and conservative reservations, including ambiguous usage. Costs are uncached-rate estimates, not verified invoices. No account balance or infinite-credit assertion has been verified.

**Provider facts, reported by official sources and read-only metadata:** all three selected models report 1,048,576 context and tools/serverless support. Kimi and GLM pages allow requesting output up to the context, with automatic reduction for prompt space. Rates used per million input/output tokens: Kimi $3/$15; GLM $1.40/$4.40; DeepSeek $0.30/$1.20. DeepSeek's page disagrees with itself: its FAQ reports lower rates; the ledger uses the higher header rates. Actual billed amounts remain unknown. Sources: [Kimi K3](https://fireworks.ai/models/fireworks/kimi-k3), [GLM-5.3](https://fireworks.ai/models/fireworks/glm-5p3), [DeepSeek V4.1 Flash](https://fireworks.ai/models/deepseek-ai/deepseek-v4p1-flash), [reasoning guidance](https://docs.fireworks.ai/guides/reasoning). Read-only API responses are preserved under preflight/provider-model-metadata/; these are not inference trials.

**Inferred analysis policy:** report rewards by task and model family with denominators and exclusions, rather than pool proxy families into a frontier estimate. Eight trials per family still have substantial sampling uncertainty. Full trajectory review and new forecasts require the actual completed evidence; none are prereported as findings.
