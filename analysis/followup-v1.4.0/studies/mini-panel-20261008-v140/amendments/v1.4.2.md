# Corrected operational handoff · v1.4.2

**Verified bug:** Harbor creates the top-level job result file before completion. The v1.4.1 handoff incorrectly treated that file as completion evidence and prematurely labeled ten still-running original attempts InterruptedHostProcess. Ten replacement attempts were dispatched while their original attempts remained active. No original paid generation was deliberately canceled. The temporary active total reached fifty, exceeding the intended ceiling of forty. These bookkeeping records are not evidence of model failure.

**Verified infrastructure limit:** twenty-one of the fifty child attempts returned RuntimeError during environment setup because Docker's default address pools were fully subnetted. These are infrastructure failures, excluded from model difficulty. The main container already has network_mode=none. The v1.4.2 overlay also assigns the unused sidecar network_mode=none, eliminating its default bridge allocation. A real Harbor oracle passed under the new overlay with reward 1, no exception. Docker was not restarted.

**Correction:** preserve the paused original and v1.4.1 dispatchers' paid children. Completion is determined from the actual child process exit, with PID/command identity checks, followed by reading the actual Harbor trial result. Original premature records and partial trajectories remain preserved; corrections and completed trajectories receive separate versioned paths. The original a1 attempt remains primary regardless of its outcome. Its prematurely dispatched a2 duplicate is excluded regardless of its outcome. This avoids choosing the better of duplicate results. Shared usage accounting includes all actual attempts, including duplicates. The primary design remains 120 trials, but the handoff caused ten additional duplicate attempts; do not claim otherwise.

**Resume:** the new dispatcher admits no new work while the inherited active count is at least forty. It maintains the 3 GiB admission reserve, records critical memory pressure and stops new dispatch on a kernel memory termination. Operational setup failures may receive the existing policy's fresh replacements under the corrected overlay. The existing three successful model smokes remain applicable because the inference client and parameters did not change. After inherited children exit, both old paused services are removed. New trials run under a separate system-supervised service.

**Verified preflight:** source hashes matched; 27 inherited child processes were still running and 23 had actual trial result files at the check. VM MemAvailable was 10471 MiB, kernel oom_kill counter zero, and the amended-overlay oracle passed. These measurements are timestamped snapshots, not future guarantees. See v1.4.2-preflight.json. The original task packages, Day 1 freeze, and v1.4.0/v1.4.1 source remain unchanged.
